# Task

`start` asks "what should we do?"; this one is told, and asks only "what do I need to know to do it?"

1. Read `index.md` and `context/state.md`. From the index, open only the to-dos, decisions and logs that touch this job. Nothing else.
2. If the job matches an open to-do, say so: closing that to-do is part of finishing.
3. State the job back in one line, with a done-test: how you will both know it is finished ("the chart is saved in figures/ and shows all ten years"). Ask if that is right; that is the only question before work starts.
4. Do the job in small steps, showing each result.
5. When it is done, offer `close`.
