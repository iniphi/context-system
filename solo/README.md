# solo

The routines for one person working with agents, on one or several devices.

Written: `chat.md`, the chat-only version (any chat that can read a public page; the person keeps a save block).

To be written here, as prompts any agent can follow (DESIGN.md, sections 2 and 3):

- `start.md`: open a session; the first time, the interview (what is this for, where will it live).
- `close.md`: end a session; the seven steps, saved and read back in whichever store was chosen.

What one person needs that a team does not: nothing beyond the loop. Conflicts come from devices, not people.

Worked example: `../examples/github/`.
